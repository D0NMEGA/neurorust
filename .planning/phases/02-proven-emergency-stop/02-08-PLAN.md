## Trust boundaries

This is the only plan in the phase that touches the physical machine and the only one that runs
anything as root. Its threats are about a number that is not what it claims to be, and about
collateral damage to a schedule that cannot be backfilled.

| Boundary | Description |
|----------|-------------|
| dev host -> rig, over rsync | The push writes into a tree that also holds captures the dev host has never seen. |
