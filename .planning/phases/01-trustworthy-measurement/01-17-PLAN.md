<objective>
Close audit finding 7: stop a failed capture from taking its own evidence with it, and stop
normalising interference counters by a duration nothing was measured over.

Purpose: two defects, both in `crates/cli/src/cmd/run.rs`, both of which make an honest record
impossible rather than merely inconvenient.

The first is at line 329. Raw tool output is written into a `tempfile::tempdir()` and only moved
into a durable run directory at line 393, after parsing, reconciliation and the contamination
verdict have all succeeded. Every one of those steps can return `Err`. When one does, the
`TempDir` is dropped, the raw capture is deleted, and the only surviving trace of an hour on the
rig is a message on stderr. A capture that cannot be parsed is still evidence: it is evidence
about the tool, the kernel, or the harness, and BENCH-06 requires failure cases to be reported
rather than omitted. "Not usable for numerical analysis" has to be an outcome the repository can
hold.

The second is at line 383. The interference snapshots bracket cyclictest, plus hwlatdetect, plus
parsing, plus the environment snapshot, but the delta is divided by `args.duration`, the
cyclictest duration alone. A 3600 second cyclictest followed by a 900 second firmware screen puts
roughly 4500 seconds of counter accumulation over a 3600 second denominator. An investigation run
that terminates early has the mismatch in the other direction. Every per-run-hour figure this
project publishes comes out of that division.

Runs entirely on the macOS dev host. No rig access, no captures.

Output: a durable attempt record written before the first instrument starts, a published index
that shows failed attempts, and interference windows measured per instrument with a monotonic
clock.
</objective>

```rust
/// The durable record of one execution of `nrmeasure run`, written before the first
/// instrument is spawned and updated on every exit path.
///
/// Raw output used to live in a `tempfile::tempdir()` until parsing, reconciliation and the
/// contamination verdict had all succeeded, so any failure among them deleted the capture.
/// An hour of rig time then survived only as a line on stderr. Finding 7 of
/// `01-EXTERNAL-AUDIT.md`.
#[derive(Serialize, Deserialize, JsonSchema, Debug, Clone, PartialEq)]
#[serde(deny_unknown_fields)]
pub struct AttemptRecord {
    pub schema_version: u32,
    pub run_id: String,
    pub utc_start: OffsetDateTime,
    pub utc_end: Option<OffsetDateTime>,
    pub status: AttemptStatus,
    pub harness: HarnessInfo,
    /// What the operator asked for: run class, instrument class, CPU list, and each
    /// instrument's requested duration. Recorded up front so a failed attempt still says
    /// what it was trying to do.
    pub requested: RequestedRun,
    /// Every tool that was spawned, with its exit code, as far as execution got.
    pub tools: Vec<ToolInvocation>,
    /// Every file kept from this attempt, checksummed. On a failure this is the partial
    /// output and the captured stderr; on success it is the same set the manifest lists.
    pub preserved: Vec<ArtifactRecord>,
    pub failure: Option<AttemptFailure>,
    /// False whenever the numbers could not be produced. A reader must be able to tell a
    /// run that measured nothing from a run that measured zero.
    pub usable_for_numerical_analysis: bool,
}

#[derive(Serialize, Deserialize, JsonSchema, Debug, Clone, PartialEq)]
#[serde(rename_all = "kebab-case")]
pub enum AttemptStatus { InProgress, Completed, Failed }

#[derive(Serialize, Deserialize, JsonSchema, Debug, Clone, PartialEq)]
#[serde(deny_unknown_fields)]
pub struct AttemptFailure {
    /// Which step failed, one of: tool-spawn, tool-exit, parse, reconcile, verdict,
    /// environment-snapshot, manifest-write.

    /// The error as reported, verbatim.

}
```

<threat_model>
## Trust boundaries

| Boundary | Description |
|----------|-------------|
| a failing run -> the repository | The moment a capture is worth hiding is the moment it failed, and until this plan the failure path deleted it automatically |
| the published index -> the set of runs that happened | An index that can only show successes is a filter, whatever its intent |
| a counter delta -> a per-hour rate | The denominator is where an interference figure is quietly wrong, and nothing downstream can detect it |
